# 3D Print Files

This directory contains printable stands for the following devices.

---

## Guition 1.80" "Silver Puck" — JC3636W518

<img width="400" src="https://github.com/user-attachments/assets/bd0ea86c-1b00-4da8-9bc5-e48d20d9b958" />

### Files

* **Guition_Silver_Puck-Stand.3mf** - Bambu Lab 3MF file with and without Mic hole.

* **Guition_Silver_Puck-Stand.stl** - Standard STL file for other slicers and 3D printers - with Mic hole.

* **Guition_Silver_Puck_NO_mic_hole-Stand.stl** - Standard STL file for other slicers and 3D printers - without Mic hole.

### Required Hardware

USB cable & power cables with fairly slim plugs Personally i use this for the audio jack: https://www.aliexpress.com/item/1005007061609551.html

## Guition P4 7.0" — JC1060P470C

<img width="400" src="https://github.com/user-attachments/assets/96801b4a-086f-4995-84b5-11adc82459af" />


### Files

* **Guition P4 7.0 Stand.3mf** - Bambu Lab 3MF file with the recommended print settings included.

* **Guition P4 7.0 Stand.stl** - Standard STL file for other slicers and 3D printers.

### Required Hardware

* 4 × M2 bolts
* 5 mm length

Any suitable M2 bolts should work. I used [these bolts from AliExpress](https://www.aliexpress.com/item/4000026780118.html), selecting:

* **M2**
* **DK: 7 mm**
* **Length: 5 mm**
